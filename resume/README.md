### プロジェクト概要

| 項目 | 内容 |
|:--- |:--- |
| **期間** | 2024年4月 〜 2025年3月 |
| **カテゴリ** | Webサービス / 自社プロダクト |
| **概要** | 社内Webサービスのインフラ運用保守 |
| **担当工程** | クラウド環境のメンテナンス |
| **ロール** | メンバー / インフラ |
| **体制** | 運用保守2名 |
| **手法** | スクラム |
| **技術スタック** | EC2, RDS, S3, EFS, ECS, ECR, Lambda, EventBridge, CloudWatch, ALB, SQS |
| **周辺ツール** | Mackerel, GitHub Projects, Redash |

### 課題
前任のインフラ担当が退職したことで、各種インフラリソースがメンテナンスされないまま放置されている状況が続いていました。社内ではCTO以外にインフラに精通したメンバーがおらず、適切な管理やアップデートが行えない状態に。
そこで、前職でサーバー構築経験があった私がアサインされ、インフラのリソース改善を進めることになりました。

### 取り組んだこと
特に費用対効果の高かった対応を上げます。
* RDS (MySQL 5系) のAWSサポート終了対応
* CentOSサポート停止に伴うOS移行
* APPサーバーへのDoS攻撃頻発とサービスダウンへの対策
* 冗長性担保のためのAPPサーバー分離

### 成果
* コスト圧縮
* セキュリティリスク低減
* APPサーバーのパフォーマンス及び安定性向上

## 受託開発

### プロジェクト概要

2022年3月 〜 2023年2月の期間で、複数の案件を同時並行で担当。

| プロジェクト名 | 概要 |
|:--- |:--- |
| **SSOを用いた業務効率化システム** | 紙からWEBへ移行し、営業実績・進捗確認を効率化。 |
| **保険明細閲覧システム** | 印刷配布していた各種明細をWEBで閲覧可能に。 |
| **検診予約システム** | 紙での予約をWEBで完結。 |
| **ワクチン予約システム** | 接種予約をWEBで完結。15自治体ほどの予約システムを運用管理。 |
| **給与明細閲覧システム** | 給与明細閲覧と、明細添付の従業員専用クーポン利用。 |

**共通技術スタック**

| 項目 | 内容 |
|:--- |:--- |
| **フロントエンド** | jQuery, Bootstrap4 |
| **バックエンド** | PHP (ピュア) - 7.4 |
| **インフラ** | AWS または さくらのクラウド |
| **監視** | Zabbix |

### 課題

開発依頼が多数ある一方で、プログラマーの人員不足が慢性的に続いていました。

### 取り組んだこと

* 月300時間以上の高稼働で対応し、すべての案件の納期を遵守しました。
* 顧客との打ち合わせから仕様策定、設計、実装までを一貫して担当しました。
* 独自フレームワークを使用し、リリースまでの開発スピードを最大化しました。

### 成果

* すべての案件を納期内にリリースし、遅延を発生することなく期限通りに納品することができました。
* 顧客満足度が高く、継続案件や追加発注を獲得しました。前年比売上120％。
